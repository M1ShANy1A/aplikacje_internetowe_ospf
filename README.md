# OSPF - strona edukacyjna

Prosta statyczna strona internetowa o protokole routingu OSPF (Open Shortest Path First). Omawia podstawy routingu, działanie OSPF, obszary, różnice między OSPFv2 i OSPFv3 oraz przykładową konfigurację Cisco IOS.

Wykorzystane technologie: HTML5, CSS3, JavaScript, Git i GitHub, GitHub Pages.

Opublikowana strona: https://m1shany1a.github.io/aplikacje_internetowe_ospf/
